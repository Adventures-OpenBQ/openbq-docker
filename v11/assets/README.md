# v11 assets

`temporaldb-logo.svg` is the TemporalDB logo: the stacked-layers glyph with a
clock hand from the header of
[secretoftheuniverse.com/temporal.html](https://secretoftheuniverse.com/temporal.html),
paths unchanged and drawn in the site accent `#22c99b`. It is laid out as an app
icon in the same family as `examples/episode3/assets/bdobb-logo.svg`: a
`#12161d` 128-unit tile with the 32-unit glyph at `translate(16 16) scale(3)`.

It is not served yet. The lanes hook serves only `/openbq/bdobb-logo.svg`, and
adding a second route is a separate, tested change.
