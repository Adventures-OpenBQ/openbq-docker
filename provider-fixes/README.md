# Provider compatibility overlay

Reviewed sources from OpenBQ PRs [7746](https://github.com/openbq-org/OpenBB/pull/7746) and [7747](https://github.com/openbq-org/OpenBB/pull/7747), commits `2462711` and `c2c8b60`. The application script verifies package versions and every original source hash before copying any file. It fails closed on upstream drift. Remove this overlay when published provider versions include the fixes. No credentials are required for applying it.

`openbb_core/app/command_runner.py` is a local fix with no upstream PR yet. Commands do CPU-bound work (pandas strategy pricing, curve bootstraps over whole DTCC day slices) in sync and async code, and on the server's single event loop one such command froze every route, `/widgets.json` included. The overlay runs each provider's commands on that provider's own persistent event loop in its own thread, and runs CBOE and CFTC commands one at a time. `openbb_finra/models/bond_list.py` and `openbb_federal_reserve/models/institution_structure.py` change only default parameters, FINRA bonds to Treasuries and FFIEC institution structure to transformations, because the upstream defaults built 150–160 MB responses.
