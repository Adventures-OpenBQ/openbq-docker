# Provider compatibility overlay

Reviewed sources from OpenBQ PRs [7746](https://github.com/openbq-org/OpenBB/pull/7746) and [7747](https://github.com/openbq-org/OpenBB/pull/7747), commits `2462711` and `c2c8b60`. The application script verifies package versions and every original source hash before copying any file. It fails closed on upstream drift. Remove this overlay when published provider versions include the fixes. No credentials are required for applying it.

`openbb_core/app/command_runner.py` is a local fix with no upstream PR yet. Commands do CPU-bound work (pandas strategy pricing, curve bootstraps over whole DTCC day slices) in sync and async code, and on the server's single event loop one such command froze every route, `/widgets.json` included. The overlay runs each provider's commands on that provider's own persistent event loop in its own thread, and runs CBOE and CFTC commands one at a time. `openbb_finra/models/bond_list.py` and `openbb_federal_reserve/models/institution_structure.py` change default parameters, FINRA bonds to Treasuries and FFIEC institution structure to transformations, because the upstream defaults built 150–160 MB responses; FINRA MBS is also capped at the first 250,000 TRACE records (with a warning), because uncapped it is 1.5M rows, a 2 GB response and about 11–12 GB of server memory. `openbb_core/api/router/commands.py` lets the app start with `OPENBB_API_AUTH=true`: openbb-core 2.0.1 rebuilt a shared endpoint's signature per route (duplicate `__authenticated_user_settings`) and placed that parameter after keyword-only ones. `openbb_cftc/utils/fx_valuation.py` builds each pair's forward curve once per day with the shared `ndf_forward_curve`, over all of the pair's prints (package legs included), so valuation and the vol surface use the same curve; options are priced once per pair, day and family. Upstream re-extracted the pair for every print (a leave-one-out curve), which made a forex swap_trades call quadratic (over an hour of CPU on a 43k-trade day); the 57,536-print slice of 2026-10-08 now values in about 5 seconds. Marks move slightly because each print's own trade is now in its curve (OpenBQ PR [7750](https://github.com/openbq-org/OpenBB/pull/7750), as revised in review).

`openbb_deribit/assets/apps.json` moves four cards on the Deribit Analysis tab down 13 rows: upstream placed options stats at y=72 inside the options surface (y=65, h=20), so Workspace pushed four cards down on first display. `scripts/verify-app-layouts.py` checks every served tab for overlapping cards.

The following fixes are filed upstream as OpenBQ PRs 7751, 7752 and 7754-7761. `openbb_core/api/exception_handlers.py` read `error.errors` without calling it, so a provider input missing from the request returned 500 instead of 422; only a field missing from a `QueryParams` subclass (any name) is a 422, so a provider `Data` model failing on an upstream response that dropped a key stays a 500. It also maps a `TimeoutError` raised by a command to 504 and a body that is not valid JSON to 502, each with a clear message; `openbb_core/api/app_loader.py` registers those two exceptions by type so their responses pass through the CORS middleware, which the catch-all `Exception` handler is outside of. `openbb_core/app/provider_interface.py` keeps a provider-only required input optional on the shared route but marks that provider's widget input `optional: false` (query parameters only, not `Data` fields), so the client asks for it instead of sending null.
`openbb_federal_reserve/federal_reserve_router.py` and `openbb_federal_reserve/ffiec.py` read the file viewers' `url` selection as `params.get("url") or []`, as the BLS routers do: upstream iterated `params.get("url", [])`, so a `{"url": null}` body from any of the 17 Fed multi-file viewers raised a TypeError (500) instead of returning `[]`. `openbb_government_us/usda/models/weather_bulletin_download.py` does the same for the USDA Weather & Crop Bulletin viewer: the route passes the whole body as `urls`, and upstream's validator failed on `{"urls": null}` and on a body without `urls` (500); both now return `[]`.
`openbb_sec/models/institutions_search.py` asks for a name when the search query is blank (400) and its widget marks `query` required; upstream passed `None` to `str.contains` (500), and returning every filer would be about 1.06 million rows. `openbb_federal_reserve/models/regional/dallas_bcs.py` and `dallas_igrea.py` pick the workbook sheet by its old name, then its new name (`BCS_Index_Results`, `Kilian Index`), then the only sheet, because the Dallas Fed renamed the sheets; the column layouts are unchanged. `openbb_government_us/usda/utils/ers_vegetables_and_pulses.py` and `ers_livestock_and_meat_domestic_data.py` read the renamed zip members (`vegetables-pulses-data.csv`, `Meat-Supply-Disappearance.csv`, `Meat-Statistics.csv`) case-insensitively and fall back to the old names; the CSV columns are unchanged. `ers_farm_household_income_and_characteristics.py` reads preliminary years such as `2025P` and sorts them like forecast `F` years.
Upstream-format fixes. `openbb_fred/models/tips_yields.py` drops `5` from the `maturity` choices, because FRED publishes no live 5-year TIPS (every 5-year series in release 72 is discontinued) and `maturity=5` raised a `KeyError` from `melt` (500); it is now a 422 (OpenBQ PR [7757](https://github.com/openbq-org/OpenBB/pull/7757), as revised in review). A date range with no observations still raises that `KeyError`. `openbb_famafrench/utils/constants.py` maps Australia to `Austrlia.Dat`, the name inside Ken French's country zips. `openbb_cboe/utils/helpers.py` coerces non-numeric settlement prices to null; the options file prints `CAB` for cabinet trades. `openbb_nasdaq/models/calendar_splits.py` makes numerator and denominator optional, because Nasdaq lists percentage stock dividends (`5%`) whose ratio has no `a : b` form; the row keeps its published `ratio_display`. `openbb_federal_reserve/models/list_of_banks_peer_group.py` rounds fractional thousands to whole dollars for its integer fields. The Kansas City Fed Ag credit survey, interest rates and finance databook keep their document ids but now carry quarter-versioned file names, so they resolve the current URL from the index page with `resolve_kc_ag_url`, as the district surveys already do, inside the cache producer.
`openbb_us_eia/eia_router.py` gives 25 EIA dataset widgets a `limit` of 5000 and a hidden `sort` of `desc`, so they open on the newest API page. Unfiltered, those datasets match more rows than the 500,000-row pagination ceiling and the request is refused; the REST defaults (full pagination, ascending) are unchanged. `openbb_tmx/routers/equity.py` and `openbb_tmx/tmx_router.py` drop the TMX screener builder from `widgets.json` and the TMX app, because it needs `pywry` (the `builder` extra), which the image does not install.

NY Fed SOFR, EFFR and OBFR return fractional rates. Their rate, target-range, percentile and intraday rate columns use `normalizedPercent`, matching Workspace Lite’s x100 display contract. Volume and standard-deviation fields retain their existing formatting; REST results are unchanged. `test_ny_rate_units.py` guards this contract.

The provider serves a static `assets/regional/ny_widgets.json` catalogue in preference to generated column definitions. Apply the same correction there and in the router metadata; testing only the router does not qualify `/widgets.json`. Both copies are covered by the pristine-package hash guard and the rate-unit regression tests.

`openbb_tmx/utils/documents.py` lets the TMX file viewers (`filings_view`, `document_view`) read only https URLs on the hosts TMX serves those documents from: `app.quotemedia.com` for filings and `spindices.com`, `us.spindices.com` and `www.spglobal.com` for index documents. Upstream fetched any URL the request named, including services on the internal network; any other URL is now a 400 before a request is made, as the SEC fetchers already refuse hosts other than sec.gov.
