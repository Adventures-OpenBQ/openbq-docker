## Test harness (shared)

- `Dockerfile.v3` gets a named stage `odp` ending after the locked `pip install`, so tests run
  against pristine pinned wheels: `docker build -f Dockerfile.v3 --target odp` (Dockerfile.v3 is now the `Dockerfile` stage `v3`; `odp` is a stage of `Dockerfile`).
- `scripts/test-provider-fixes.sh` builds that stage, runs `provider-fixes/apply.py`, then
  `python -m unittest discover provider-fixes/tests`. Stdlib `unittest` only (no pytest in the
  lock). Offline fixtures; no network in unit tests.
- Every new overlay file: pristine copy hash in `original-sha256.json`, package pin in
  `apply.py`'s version list. Tests are written first and must fail on the pristine source.
